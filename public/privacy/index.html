    プライバシーポリシー

    最終更新日：2026年11月23日

    第1条から第9条はNIARIMアプリの正式なプライバシーポリシーと共通の内容です。公式サイトでの情報の取扱いは、最後の節に記載しています。

    第1条（本ポリシーの位置づけ）

    このプライバシーポリシー（以下「本ポリシー」といいます。）は、本アプリ「NIARIM」（以下「本アプリ」といいます。）における情報の取扱いについて定めるものです。本ポリシーにおいて「開発者」とは、本アプリの提供者をいいます。開発者の氏名または名称および住所は、第9条の窓口へご請求いただければ遅滞なくお知らせします。本アプリの利用条件全般については別途「利用規約・ライセンス」画面をご確認ください。

    第2条（本アプリが取得しないデータ）

    本アプリは、ユーザーが作成したイラスト・アニメーション等のコンテンツ（プロジェクトデータ・書き出し画像・動画等を含みます。以下同じです。）を、開発者のサーバーへ送信・収集・保存する機能を提供していません。これらのデータは、原則としてユーザーの端末内にのみ保存されます。（クラウド同期機能は搭載していません。）開発者はこれらのコンテンツを自ら保存する機能を持たないため、開発者側での保存期間という概念自体がありません。端末内に保存されたデータは、本アプリの削除機能により随時削除できるほか、アプリをアンインストールした場合はプロジェクト・設定・追加したフォント等のデータも併せて削除されます。（ただし、ユーザーが自らの意思でGoogleアカウントでログインし、作品広場・オパール・プレミアムの購入の確認を利用する場合の情報の取扱いについては、第7条によります。）

    開発者は、ユーザーが作成または投稿したコンテンツ、プロジェクトデータその他の制作データを、生成AIモデルその他の機械学習モデルの学習データとして利用しません。

    第3条（第三者サービスによる情報の取得）

    本アプリは、以下の第三者サービスを組み込んでおり、それぞれのサービス提供者が、サービス提供に必要な範囲で情報を取得する場合があります。本アプリの開発者は、これらの情報を独自に取得・保存する機能を実装していません。（各サービスが取得した情報の管理は、それぞれのサービス提供者のプライバシーポリシーに従います。） 【広告配信（Google AdMob）】 無料版では、Google AdMobを通じて広告を配信しています。広告の配信、効果測定、不正防止等の目的で、広告識別子（Advertising ID）その他の端末情報が、Googleまたはその関連事業者によって取得・利用される場合があります。取得・利用の詳細は、Googleのプライバシーポリシー（https://policies.google.com/privacy）をご確認ください。端末の設定（Android設定アプリの「プライバシー」等）から、広告識別子のリセットや、パーソナライズ広告の無効化が可能です。欧州経済領域（EEA）・英国・スイスにお住まいの場合は、起動時等に表示される同意フォームで、広告のパーソナライズに関する同意設定を選択できます。設定はいつでも本アプリのプライバシーポリシー画面の下部にある「広告の同意設定を変更」ボタンから変更できます。 【アプリ内課金（Google Play Billing）】 プレミアム機能の購入は、Google Playの決済システムを通じて行われます。クレジットカード番号等の決済情報は、開発者側が直接取得・保持することはありません。決済に関する情報の取扱いは、Google Playの規定に従います。 【Googleアカウントでのログイン（Google Sign-In）】 作品広場・オパール・プレミアムの購入の確認を利用するときに限り、Googleアカウントでログインします。ログインの際、Googleから本アプリへ、アカウントの識別子・メールアドレス・表示名等を含む本人確認の情報が渡されます。開発者のサーバーは、この情報を本人確認とNIARIM User ID（第7条）の発行・照合にだけ使い、メールアドレスと表示名を保存しません。 【YouTube（YouTube APIサービス）】 作品広場は、YouTube APIサービスを利用しています。作品を投稿するときは、ユーザーがGoogleアカウントで許可した権限で、動画をユーザー自身のYouTubeチャンネルへアップロードし、チャンネル名とアイコンを取得します。投稿した動画は、YouTubeの利用規約（https://www.youtube.com/t/terms）とGoogleのプライバシーポリシー（https://policies.google.com/privacy）に従って扱われます。本アプリへの許可は、Googleのセキュリティ設定のページ（https://security.google.com/settings/security/permissions）からいつでも取り消せます。 【プッシュ通知（Firebase Cloud Messaging）】 作品広場の通知を有効にした場合に限り、通知を届けるため、Google（Firebase Cloud Messaging）が端末ごとの通知用の識別子（端末トークン）を発行します。 【開発者のサーバー（Amazon Web Services）】 作品広場・オパール・プレミアムの購入の確認に使う開発者のサーバーは、Amazon Web Services, Inc.が提供するクラウド（日本の東京リージョン）で運用しています。 【追加フォントのダウンロード（GitHub）】 設定画面の「フォント管理」から追加フォントをダウンロードする操作を行った場合に限り、フォントの配布元であるGitHub（GitHub, Inc.）のサーバーへ通信が発生します。この通信はお客様がダウンロードを選択したときにのみ行われ、アプリの起動時や通常の利用では発生しません。送信されるのは通信に必要な情報（IPアドレス、取得するフォントファイルの指定等）のみで、作品データやお客様を特定する情報を送信することはありません。取得された情報の取扱いは、GitHubのプライバシーポリシー（https://docs.github.com/site-policy/privacy-policies/github-privacy-statement）に従います。 【クラッシュ解析・利用状況分析】 本アプリは、現時点でクラッシュ解析・利用状況分析を目的としたSDKを組み込んでいません。将来これらのサービスを導入する場合は、本ポリシーを更新し、本アプリ内で告知します。

    第4条（Cookie等のトラッキング技術について）

    本アプリ自体はCookieを使用しませんが、第3条記載の広告配信サービス（Google AdMob）が、広告の配信・効果測定のために、これに類する識別技術（広告識別子等）を使用する場合があります。

    第5条（お子様の個人情報について）

    本アプリは、13歳未満のお子様を主な対象として意図的に情報を収集するものではありません。保護者の方は、お子様が本アプリを利用する際、必要に応じて端末の設定からパーソナライズ広告の無効化等をご検討ください。

    第6条（情報の越境移転について）

    本アプリが利用する次のサービスの提供者は日本国外の事業者であり、情報が日本国外のサーバーで処理される場合があります。 ・Google LLC（米国）：Google AdMob、Google Play Billing、Googleアカウントでのログイン、YouTube、Firebase Cloud Messaging ・Amazon Web Services, Inc.（米国）：開発者のサーバーの運用（サーバーは日本の東京リージョンに置いています） ・GitHub, Inc.（米国）：追加フォントのダウンロード 米国の個人情報の保護に関する制度は、個人情報保護委員会が公表している「外国における個人情報の保護に関する制度等の調査」で確認できます。各事業者は、それぞれのプライバシーポリシーに従って情報を取り扱います。

    第7条（作品広場・オパール・プレミアムの確認における情報の取扱い）

    1. 本アプリは、ユーザーが自らの意思でGoogleアカウントでログインし、「作品広場」機能（利用規約第12条）、オパール（ログインボーナス・ミッション・特典との交換）またはプレミアムの購入の確認を利用する場合に限り、以下の情報を開発者のサーバーで管理します。 ・投稿作品を識別・表示するための情報（YouTube動画ID、タイトル、統計情報、投稿日時、タグ等） ・ログインしたユーザーに発行するNIARIM User ID（Googleアカウントとは別に本アプリ内部で発行する識別子） ・連携したYouTubeチャンネルの公開情報（チャンネル名、チャンネルアイコンの画像URL）。これは投稿者名・アイコンの表示に用いるため、開発者のサーバーに複製して保持します ・通報機能を利用した場合の通報内容および通報者のNIARIM User ID ・ブロックした相手のNIARIM User ID ・フォローした相手のNIARIM User ID、およびフォロー数・フォロワー数 ・ブックマークした作品のIDおよびブックマークした日時 ・リポストした作品のIDおよびリポストした日時 ・作品に付けられたタグ（第4項参照） ・プッシュ通知を有効にした場合の端末トークン（通知の宛先を特定するために端末が発行する識別子。通知の送信のみに用います） ・プレミアムの購入を確認するための情報（購入した商品のID、Google Playが発行する購入トークン、確認の結果と有効期限） ・オパールの残高と増減の履歴、ログインボーナス・ミッションの達成と受け取りの記録、特典との交換の記録 ・リワード広告を最後まで見たことの確認の記録（Google AdMobから届く報酬の確認の取引ID・報酬の量・日時） 2. 投稿された動画ファイル本体はYouTube上に保存され、開発者のサーバーには保存されません。 3. 前2項の情報は、本条の機能の提供（作品の一覧表示・ランキング・検索、通報への対応、投稿上限の管理、フォロー・ブックマーク・リポストの反映、通知の送信、プレミアムの購入の確認、オパールの付与・交換と不正な付与の防止等）の目的の範囲内でのみ利用します。開発者はこれらの情報を広告配信の目的で第三者へ提供しません。 4. タグは、投稿者以外のユーザーも追加・削除できます（投稿者は自分の作品のタグをロックして編集を禁止できます）。タグは作品広場上で公開され、誰が付けたかは表示されません。 5. フォロー中のユーザー、フォロワー、ブックマークした作品の一覧は、本人だけが閲覧できます。他のユーザーには、フォロー数とフォロワー数だけを表示します。フォロー、ブックマークまたはリポストを行っても、相手にその操作を知らせる個別通知は送信されません。 6. 投稿作品を非公開にする、または削除した場合、当該作品は作品広場の一覧・ランキングから表示されなくなります。NIARIMのアカウント（NIARIM User ID）は、アプリの設定または公式サイトのプライバシーポリシーから開く削除ページで、Googleアカウントによる本人確認のうえ、ユーザー自身の操作で削除できます。削除すると、当該アカウントに結びつく作品広場の投稿・フォロー・ブックマーク・リポスト・ブロック・通報、オパールの残高・履歴・特典、通知と端末トークン等を順次削除し、元に戻すことはできません。削除後は、次のものだけを保持します：古いログインを受け付けないためのGoogleアカウントの識別子のハッシュ値（2時間）、手続きの完了を確認するための個人を識別しない記号（24時間）、広告報酬の二重付与を防ぐための、個人を識別する情報を取り除いた受付記録（既存の有効期限まで）、削除した作品が再び表示されないようにするための作品IDのみの記録。障害時に一時的に保存したデータは7日以内、サーバーの記録（ログ）は1か月以内に自動で削除されます。端末内の作品、YouTube上の動画、Google Playの定期購入は本削除の対象外のため、それぞれの場所で管理・解約してください。その他の記録の削除を希望する場合は、第9条の窓口へご連絡ください。 7. 開発者は、前各項の情報を守るため、サーバーとの通信を暗号化し、サーバーの情報を扱える者とその権限を必要な範囲に限っています。 8. 本条の機能を利用しない場合、本条に基づく情報の取扱いは発生しません。（第2条の原則どおり、開発者のサーバーへの送信は行われません。）

    第8条（本ポリシーの変更）

    開発者は、法令の改正、本アプリの内容の変更その他必要と判断した場合、本ポリシーを変更することがあります。本ポリシーを変更する場合、変更内容および効力発生日を、本アプリ内その他適切な方法により、事前に周知します。

    第9条（開示等の請求・苦情・お問い合わせ）

    1. ユーザーは、開発者が保有するご自身の個人情報について、利用目的の通知、開示、訂正・追加・削除、利用の停止・消去、第三者への提供の停止を請求できます。下記の窓口へご連絡ください。ご本人であることを確認したうえで、法令に従い遅滞なく対応します。手数料はいただきません。 2. 本ポリシーおよび個人情報の取扱いに関する苦情・ご相談も、下記の窓口で受け付けます。 3. 欧州経済領域（EEA）・英国・米国の一部の州などにお住まいの方は、お住まいの地域の法令に基づく権利（アクセス、訂正、削除、処理の制限、データポータビリティ、異議、同意の撤回、監督機関への苦情の申立て等）を行使できます。開発者は、第7条の情報を、ユーザーが求めた機能を提供するため（契約の履行）および不正を防ぐため（正当な利益）に処理します。広告のパーソナライズは、第3条の同意フォームで選んだ設定に従います。開発者は個人情報を販売しません。 本ポリシーに関するお問い合わせは、本サイトのお問い合わせフォームよりご連絡ください。

    公式サイトでの情報の取扱い

    本節は、NIARIMの公式サイト（以下「本サイト」といいます。）での情報の取扱いを定めます。 1. お問い合わせフォーム：入力されたお名前・メールアドレス・お問い合わせ内容・添付ファイルは、お問い合わせへの回答のため、メール送信サービスのResend（Resend, Inc.、米国）を通じて開発者のメールボックスへ送られます。回答に必要な期間保管し、その後削除します。 2. 送信回数の制限：お問い合わせフォームの連続送信を防ぐため、送信元のIPアドレスごとに送信の回数と時刻を記録します。この記録は、最後の送信から24時間で自動的に削除されます。 3. 言語の保存：表示する言語を選んだ場合に限り、その言語をブラウザーのCookie（niarim_lang、有効期間1年）に保存します。本サイトは、広告・アクセス解析のためのCookieやトラッキングを使用しません。 4. 作品広場：作品広場のページでは、作品のサムネイル画像をYouTube（Google LLC、米国）のサーバーから読み込みます。その際、お使いのIPアドレスやブラウザーの情報がGoogleに送られます（Googleのプライバシーポリシー：https://policies.google.com/privacy）。 5. 配信：本サイトは、Cloudflare, Inc.（米国）のサービスで配信しています。配信と不正なアクセスの防止のため、Cloudflareがアクセスの記録（IPアドレス等）を処理します（Cloudflareのプライバシーポリシー：https://www.cloudflare.com/privacypolicy/）。 6. アカウントの削除：アカウントの削除のページでは、本人確認のためGoogleアカウントでログインします（第7条第6項）。
