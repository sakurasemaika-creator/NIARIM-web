  1. Googleのログインに使うOAuthのWebクライアントIDを、wrangler.jsonc の vars の ACCOUNT_DELETION_GOOGLE_CLIENT_ID に入れてデプロイします（バックエンドの GOOGLE_CLIENT_ID と同じ公開の値）。
  2. 同じ vars の NIARIM_PUBLIC_API_BASE_URL に、バックエンドのLambda Function URL（https）が入っていることを確かめます。
  3. Google Cloud ConsoleでそのOAuthクライアントの「承認済みのJavaScript生成元」に https://niarim.miranima-studio.com を足します。
